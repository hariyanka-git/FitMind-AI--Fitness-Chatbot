# 🏋️ FitMind AI - Fitness Chatbot & Health Intelligence Platform

An interactive web application designed to help users track workout routines, manage nutritional intake, visualize storyboards, and interact with a fitness assistant.

---

## ✨ Key Features

* **🤖 Fitness Assistant:** Interactive conversational assistant designed to offer workout suggestions and habit guidance.
* **🔐 User Authentication:** Secure signup, login, and session persistence powered by SQLite and local storage logic.
* **📊 Dashboard & Multi-Tab Hub:** Dynamic interface featuring Home, Create Your Own, Read/Storyboards, and User Settings tabs.
* **⚡ Modern Visual Architecture:** Responsive UI with clean CSS component styling across desktop and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), FontAwesome
* **Backend & Storage:** Python, Flask, SQLite, Local Storage
* **Development Environment:** PyCharm, Git, GitHub
